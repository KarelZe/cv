My cv template, based on [modern cv](https://github.com/xdanaux/moderncv/).

## Requirements
- Minion Pro font, and Myriad Pro font

## Releases
To create a new release online:
1. Go to **Actions** → **Release CV**.
2. Click **Run workflow**.
3. Optionally enter a version override or leave it empty to auto-generate the next version using calendar versioning (`YY.M.N`, e.g. `26.10.1`).
